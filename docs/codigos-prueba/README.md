# Codigos de prueba

Archivos listos para probar el escaneo desde:

- `Productos -> Nuevo producto -> Codigos iniciales -> Escanear camara / Leer imagen`
- `Codigos de barras -> Nuevo codigo -> Escanear camara / Leer desde imagen`
- `Facturas -> Nueva factura -> Catalogo visual -> Escanear / Leer imagen`

Codigos incluidos:

- `ean13-cafe-premium.png` -> `7701234567897`
- `ean8-snack-mini.png` -> `55123457`
- `upca-galletas.png` -> `042100005264`
- `code128-combo.png` -> `PROD-101-PROMO`
- `qr-producto-demo.png` -> `https://erp.local/p/101`

Archivo OCR de ejemplo:

- `factura-ocr-ejemplo.pdf`

Notas:

- El PDF de factura sirve para probar el importador OCR de productos desde `Productos -> Importar factura OCR`.
- Si vas a usar la camara, muestra cada imagen en otra pantalla o impresa para que el lector la detecte mejor.
